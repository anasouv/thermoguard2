# ThermoGuard Website

Website pembentangan 5 slaid untuk projek ThermoGuard.

## Susunan slaid
1. Isu: Anak tertinggal dalam kereta
2. Pengenalan
3. Objektif
4. Komponen utama
5. Cara sistem berfungsi + Kelebihan + Kesimpulan

## Cara upload ke GitHub Pages
1. Buat repository baru di GitHub, contoh: `website-thermoguard`
2. Upload `index.html`, `style.css`, `script.js` dan folder `assets`.
3. Pergi ke **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, kemudian Save.
6. Tunggu GitHub Pages diterbitkan.

Nota: Dua gambar rujukan yang diberi turut disimpan dalam `assets/`, tetapi reka bentuk website utama dibina menggunakan HTML/CSS supaya kandungan boleh diedit dengan mudah.
